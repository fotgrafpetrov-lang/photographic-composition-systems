# Related work / Ближайшие известные направления

This file is **not** a claim that the project is unprecedented. It records nearby concepts so future work does not waste time rediscovering the same literature search.

## Gestalt principles in photography
Gestalt theory explains perceptual grouping: proximity, similarity, continuity, closure, figure-ground, common region, connectedness, etc. Photography teaching sometimes applies these principles.

Useful sources:
- Richard D. Zakia, “Gestalt and Photography” (Gestalt Theory, 2004):  
  https://en.gestalttheory.net/uploads/pdf/GTH-Archive/2004ZakiaPhotography.pdf
- Photography Life overview:  
  https://photographylife.com/videos/gestalt-theory
- Eye-tracking study of Gestalt theory in photography:  
  https://pmc.ncbi.nlm.nih.gov/articles/PMC10644408/

Relation to this project:
Gestalt is relevant to grouping, but it does not by itself provide the current explicit workflow:
**large compositional systems → relations between systems → local tuning and compromise.**

## Pictorial composition / hierarchical organization
Alberti’s compositio has been described as a hierarchy where smaller units form larger units and the picture is treated as an interdependent whole.

Useful source:
- National Gallery, “Composing the Image”:  
  https://www.nationalgallery.org.uk/research/publications/exhibition-catalogues/building-the-picture/constructing-the-picture/composing-the-image

Relation:
Historically relevant to hierarchical organization, but not the same operational frame-level segmentation method being developed here.

## Andreas Feininger
Book:
- *Principles of Composition in Photography* (1973/1976 editions)
- ICP library record:  
  https://www.icp.org/content/principles-of-composition-in-photography

Relation:
Feininger is a close photographic neighbour in treating composition as organization and discussing spatial/graphic structure, but the current project’s explicit large-system-first analysis remains more specific.

## Michael Freeman
*The Photographer’s Eye* discusses design, Gestalt laws, visual elements, frame organization and figure-ground.

Relation:
Useful vocabulary and perceptual background; not equivalent to the project’s current system decomposition pipeline.

## Search conclusion as of 2026-09-30
A search found multiple neighbouring ideas—large shapes/masses, Gestalt grouping, pictorial organization, spatial organization—but did not identify a standard photography method matching the exact sequence:

**explicit large-system segmentation → relations among systems → subject-bearing system → local compromise balancing.**

Treat this as a search result, not a proof of novelty.
